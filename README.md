# Starlight Legacy

A stylized 3D educational exploration game built with Godot 4.

## Current direction

- Godot 4.x
- GDScript
- GL Compatibility renderer
- Web-first
- First-person exploration
- Knowledge-driven progression

## Sprint 001

The first technical slice focuses on:

- a playable first-person controller;
- a greybox workshop;
- a stable scene structure;
- a project base that stays friendly to Web export.

## Controls

- `WASD`: move
- `Mouse`: look
- `Space`: jump
- `Esc`: release/capture the mouse
